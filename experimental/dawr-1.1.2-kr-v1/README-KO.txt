Disassemble Weapons for Recipes (DAWR) 1.1.2 KR v1

첨부한 DAWR 1.1.2 원본을 기준으로 만든 한국어 번역 패치입니다. 원본 모드와 원본이 요구하는 선행 모드가 필요합니다.

번역 범위: 원본의 화면 문자열 21개 전체. 모드 이름/활성화, 등급별 제작 사양서 획득 확률, 하위 등급 사양서 획득, 테크 능력 및 엔지니어 보너스/배율 설명, 획득 알림의 제작 사양서 및 등급 문구를 번역합니다.

한국어 전용 리소스와 ArchiveXL 언어 등록 파일만 포함합니다. 원본 REDscript, 분해 확률/배율, 아이코닉 처리, 사용자 설정은 수정하지 않습니다. 원본 영어 리소스도 덮어쓰지 않습니다.

MO2 설치:
1. DAWR 1.1.2 원본을 활성화합니다.
2. 이 ZIP을 별도 번역 모드로 설치하고 원본 아래에 배치합니다.
3. MO2로 게임을 완전히 다시 실행합니다.
4. 게임의 화면 언어가 한국어인 상태에서 모드 설정의 무기 분해 제작 사양서 (DAWR) 메뉴를 확인합니다.

수동 설치: ZIP의 archive 폴더를 게임 폴더에 병합합니다. 원본 archive와 archive.xl 및 REDscript는 유지하세요.

포함 파일:
archive/pc/mod/DAWR_KR.archive
archive/pc/mod/DAWR_KR.archive.xl

게임 확인: 설정 제목/설명 및 제작 사양서 획득 알림이 한국어인지 확인하세요. 원본 모드에서 사양서 획득은 설정과 조건에 따라 확률적으로 발생하므로, 한 번 분해해 알림이 없다는 것만으로 번역 실패라고 판단할 수 없습니다.

검증: 원본 번역 키 21개와 정확히 일치, REDscript에서 사용하는 DAWR 키 전부 포함, 최신 리소스 형식/이름 테이블 보존, 바이너리 재파싱, CR2W 헤더/테이블 CRC32, 아카이브 인덱스 CRC64/리소스 SHA1, ZIP CRC 통과. 실제 게임 실행/표시는 미검증이며 원본 모드 자체의 게임 버전 호환성은 별도입니다.

문제가 있으면 최신 ArchiveXL 로그와 redscript_rCURRENT.log, 표시 화면을 보내주세요.

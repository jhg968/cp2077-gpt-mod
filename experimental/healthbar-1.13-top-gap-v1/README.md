# Informative Healthbar 1.13 — 上段/상단 간격 실험 패치 v1

목표: 정보 패널을 체력 바 위에 유지하면서 세로 여백을 확보합니다.
정보 패널의 Y 오프셋을 더 음수로 밀어내는 대신, 기본 체력 바/숫자를 담는 buffsHolder와 장식 캔버스를 아래로 이동합니다.
원본 부모 위젯에 명시적인 높이가 있는 경우 이동량만큼 아래쪽 공간을 추가합니다. 자동 크기/0 크기 부모에 임의 크기를 강제하지 않습니다.

이 패치는 스크린샷의 빽빽한 배치를 개선하기 위한 실험용 레이아웃 확장입니다. 잘림 원인이 특정 부모의 마스크인지까지 실측한 패치는 아니며, 실제 게임 컴파일과 표시 검증은 필요합니다.

## 설치

1. 게임 종료.
2. 원본 Informative Healthbar 1.13과 최신 KR 패치는 유지.
3. ZIP을 MO2에 별도 모드로 설치하고 활성화. 고유 .reds 하나를 추가하며 원본 및 번역 파일을 덮어쓰지 않습니다.
4. 게임을 새로 실행하고 Informative Healthbar의 레이아웃 & 테마 설정으로 이동.
5. 위치를 체력 바 위로 설정하고 기존 Y 오프셋을 0으로 복원.
6. 새 옵션 `상단 정보와 체력 바 간격`을 20으로 시작. 필요하면 12~30 사이에서 조절.
7. redscript 컴파일 결과와 화면을 확인. 아래쪽 RAM/스태미나 바와 겹치면 간격을 줄여 조절.

## 동작 범위

- `체력 바 위` 모드에서만 간격을 적용합니다. 아래 배치로 바꾸면 원래 변환/높이로 복원합니다.
- E3 HUD가 원본의 감지 로직에서 활성화된 경우 간격을 적용하지 않습니다.
- 기본 간격 20, 설정 범위 0~80. 0은 이 확장의 추가 이동을 없앱니다.
- 매 설정 갱신마다 기존 이동값에 계속 더하지 않고 캐시된 원래 변환에서 계산합니다.
- 정보 패널의 위젯 순서·가로 간격·번역·설정값은 바꾸지 않습니다.
- HUD root 아래의 모든 형제/조상을 일괄 이동하거나 전역 clipping 설정을 해제하지 않습니다.
- 다른 HUD 모드가 같은 위젯의 변환이나 크기를 조작하면 충돌할 수 있습니다.

## 검증 및 원복

원본 메서드/필드 참조, Codeware 소스에서의 ink 위젯 API 사용, 구조 괄호 및 ZIP 내용을 확인했습니다.
실제 게임에서의 redscript 컴파일과 시각적 결과는 미검증입니다. redscript_rCURRENT.log와 적용 화면으로 확인해야 합니다.
컴파일 실패나 표시 이상이 있으면 이 레이아웃 패치만 비활성화한 뒤 게임을 재실행해 원복합니다.

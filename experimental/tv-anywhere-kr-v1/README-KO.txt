TV Anywhere KR 호환 보완 v1

첨부한 TV Anywhere.7z 원본(MO2 meta.ini 버전 3.3.3.0)과 TV Anywhere KR.7z를 비교하여 만든 번역 전용 교체판입니다. 원본 모드가 필요합니다.

문제: 기존 KR의 화면 문구 12개는 숫자 primaryKey가 99401~99414 계열인 반면 최신 원본은 665599401~665599414 계열을 사용합니다. secondaryKey와 한국어 문구가 있어도 숫자 ID 조회가 맞지 않을 수 있습니다.

수정: 최신 원본의 화면 문구 리소스를 기준으로 12개 최신 숫자 ID를 유지하고, 동일 secondaryKey에 기존 한국어 번역을 옮겼습니다. 입력 키 안내/강조 태그는 원본과 대조했습니다. 비디오탭 줍기 자막은 기존 stringId 2182424242424242424와 남녀 번역을 유지하며 최신 리소스 형식으로 다시 작성했습니다.

기존 KR도 번역 리소스 두 개만 포함합니다. 이번 교체판 역시 동일한 두 경로만 포함하며 퀘스트/스크립트/AI/트윅/원본 XL 설정은 포함하지 않습니다.

MO2 적용:
1. 기존 TV Anywhere KR을 비활성화합니다.
2. 최신 TV Anywhere 원본을 활성화합니다.
3. 이 ZIP을 별도 모드로 설치하고 원본 아래에 배치합니다. 기존 KR 모드에 병합하지 마세요.
4. archive/pc/mod/TvAnywhere KR.archive가 새 패치에서 제공되는지 확인합니다.
5. MO2를 통해 게임을 완전히 다시 실행합니다.

수동 적용: 기존 archive/pc/mod/TvAnywhere KR.archive를 게임 폴더 밖에 백업한 뒤 이 ZIP의 파일로 교체합니다. 이전 KR 복사본을 이름만 바꾸어 같은 mod 경로에 남기지 마세요.

확인: 퀘스트 제목/목표, 빅터 메시지, 비디오탭 이름, 사용 안내, 비디오탭 줍기 자막이 한국어인지 확인하세요. 튜토리얼처럼 이미 지나간 안내는 자동으로 다시 나타나지 않을 수 있습니다. 이번 패치는 퀘스트를 재시작하거나 진행 상태를 바꾸지 않습니다.

검증: 화면 12개와 자막 1개의 최신 키 일치, 기존 한국어 문구 보존, 남녀 자막 구분 유지, Rich/Input 태그 일치, 원본 한국어 자막 맵의 실제 파일 연결 확인, CR2W 195 재파싱/헤더 및 테이블 CRC32, 아카이브 인덱스 CRC64/리소스 SHA1, ZIP CRC 통과. 실제 게임 실행/표시는 아직 미검증입니다.

오류가 있으면 최신 ArchiveXL 로그와 redscript_rCURRENT.log 및 표시 화면을 보내주세요. 이 검증은 번역 리소스 호환성에 관한 것이며 원본 모드 전체의 게임 버전 호환성을 보장하지 않습니다.

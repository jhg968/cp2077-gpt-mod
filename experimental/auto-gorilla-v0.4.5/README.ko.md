# AutoGorilla v0.4.5 — 실패 후 일반 가드 애니메이션 재시작 억제

로그의 최신 구간에서 자동 가드79회, 기본 패링/반격39회, 실패 후 일반 Block 진입40회가 관측됐습니다.
동일 상대/동일 관측 공격 상태에 중복 진입한 기록은 없었습니다.
이 버전은 실패한 Deflect 직후 자동으로 일반 Block 상태에 들어갈 때 생기는 추가 애니메이션 요청만 선택적으로 생략합니다.
별도 NPC 준비 상태와 실제 공격에 각각 반응하는 모든 가드 동작을 없애는 기능은 아닙니다.

## 범위
기존 v0.4.4 대상 감지, 패링 판정, 반격 연결과 피해 처리는 유지합니다.
실패한 자동 Deflect 종료 직후0.2초 내/같은 무기/수동 방어 버튼이 눌리지 않은 경우만 적용합니다.
일반 Block 상태 진입과 IsBlocking 스탯, 정상/강제 종료 및 스탯 제거는 그대로 둡니다.
수동 방어, 성공한 반격, 다른 무기의 애니메이션은 생략하지 않습니다.
설정에 '실패 후 중복 가드 억제'(기본 켜짐)를 추가했습니다. 끄면 기존 애니메이션 요청이 복원됩니다.
기본 MeleeBlockEvents.OnEnter 메서드 하나를 replace하며 원래 코드의 Block 애니메이션 요청만 조건부 처리합니다.
같은 메서드를 replace하는 다른 모드가 있으면 충돌할 수 있습니다. 이 경우 redscript 로그에 중복 replacement 경고가 있는지 확인해야 합니다.
게임 상태 전이를 바꾸거나 실패한 공격을 패링 성공으로 만들지 않습니다.

## 설치/테스트
게임 종료 후 이전 AutoGorilla/별도 NativeTrace를 모두 끄고 이 ZIP만 별도 모드로 활성화합니다.
MO2로 실행하고 우선 장착을 확인하세요. 이상이 있으면 중단하고 비활성화합니다.
정상이면 Mods → AutoGorilla에서 '실패 후 중복 가드 억제'와 진단 로그를 켜서 같은 전투에서 비교하세요.
기존 추가비용0/최소간격0.3초/배율1 설정은 유지할 수 있습니다. 새 옵션은 기존 JSON이 있어도 기본 켜짐입니다.
가드가 두 번 올라가는 모습이 줄었는지, 기존 반격/피해가 유지되는지 알려주세요.
끄기와 켜기를 같은 게임 실행 중 비교할 수 있습니다.
AUTO cosmetic duplicate Block animation skipped는 애니메이션 재요청이 생략된 기록입니다.
로그: bin/x64/plugins/cyber_engine_tweaks/mods/AutoGorilla/AutoGorilla.log

## 검증

게임 내 컴파일/동작/체감 반복 감소와 다른 모드 충돌은 아직 미검증입니다.
공격 상태가 두 개로 나뉜 준비 동작과 실제 타격에 각각 Deflect를 여는 경우는 이 옵션만으로 해결되지 않을 수 있습니다.

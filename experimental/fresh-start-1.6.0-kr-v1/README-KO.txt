Fresh Start 1.6.0 KR 보완 v1

Fresh Start 1.6.0 원본과 함께 사용하는 별도 번역 패치입니다. 게임 실행 검증은 아직 하지 못했습니다.

변경: 1.6.0의 화면 문구 리소스를 기준으로 기존 번역 8개를 유지하고, primaryKey 2563441513 / new_start_save_short에 기업/노마드 [FS]를 추가했습니다. 자막 21개와 남녀 대사 구분은 기존 KR 번역을 그대로 유지했습니다. 최신 자막 리소스 형식을 기준으로 다시 작성했습니다.

MO2 설치:
1. 기존 New Lifepath Intro - Fresh Start KR 모드를 비활성화합니다.
2. 이 ZIP을 새 모드로 설치합니다.
3. Fresh Start 1.6.0 원본과 이 보완 패치를 모두 활성화합니다. 기존 KR 패치와 동시에 켜지 마세요.
4. ZIP의 게임 파일은 archive/pc/mod/#FreshStart KR.archive 하나입니다. 기존 KR 파일명과 내부 리소스 경로를 유지합니다. 원본의 #FreshStart.archive와 #FreshStart.archive.xl, r6 파일은 유지하세요.

수동 설치: 기존 archive/pc/mod/#FreshStart KR.archive를 백업하고 이 ZIP의 동일 경로 파일로 교체합니다. 기존 KR 복사본을 다른 이름으로 남겨 함께 로드하지 마세요.

확인: 새 시작 관련 저장 이름, 화면 문구, 도입부 자막을 확인합니다. 짧은 이름은 기업/노마드 [FS], 일반 이름은 기업/노마드 [새로운 시작]입니다. 기존 저장 파일의 표시 이름은 저장 당시 문구를 포함할 수 있으므로 기존 목록만으로 실패라고 판단하지 마세요. 해당 기능을 사용하는 새 저장/새 표시에서도 확인해주세요.

범위: 한국어 화면 문구/자막 리소스 2개만 포함합니다. 퀘스트, REDscript, 트윅, 최신 원본 XL 설정을 덮어쓰지 않습니다.

검증: 1.6.0의 CR2W 195 형식과 리소스 이름 테이블 유지, 전체 키 일치(화면 9/자막 21), 기존 번역 보존, 남녀 자막 구분 보존, 바이너리 재파싱, CR2W 헤더/테이블 CRC32, RDAR 인덱스 CRC64, 리소스 SHA1, ZIP 무결성 확인. 게임 내 동작은 미검증입니다.

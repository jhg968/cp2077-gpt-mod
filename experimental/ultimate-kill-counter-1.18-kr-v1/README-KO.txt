Ultimate Kill Counter 1.18 KR 분리 패치 v1

첨부 원본 UltimateKillCounter 1.18과 스크린샷의 한국어 표현을 기준으로 만든 별도 번역 확장입니다. 원본 모드의 파일을 교체하지 않습니다.

설계:
원본 DataTrackingSystem.LocalizeTag(Tag, Default) 보조 함수만 @wrapMethod로 감쌉니다. 원본 1.18에서 사용하는 태그와 기본 영문 문구 12쌍을 정확히 일치시켜 한국어를 반환하고, 알 수 없는 호출은 wrappedMethod로 원본에 넘깁니다. 원본은 Kills/Killed Enemies와 원거리/퀵핵/테이크다운/비살상/기타에서 같은 번역 키를 재사용하므로 단순한 키별 사전으로 번역하면 서로 다른 통계 항목이 같은 이름으로 나올 수 있습니다. 기본 영문 문구도 함께 확인해 이를 피합니다.

집계 로직, 통계 값, 처치 이벤트, 세이브 데이터와 원본 DumpPromptFix.archive는 변경하지 않습니다. 이 확장을 켜면 해당 12개 표기는 한국어로 고정됩니다. 언어별 리소스를 추가하거나 새 프레임워크 의존성을 도입하지 않습니다.

스크린샷 기준 표기:
처치한 적 / 치명적으로 처치한 적 / 무력화된 적 처치 / 비치명적 피해로 제압한 적 / 무력화시킨 적 / 쓰러뜨린 적 / 근접 공격으로 쓰러뜨린 적 / 원거리 공격으로 쓰러뜨린 적 / 퀵핵으로 쓰러뜨린 적 / 테이크다운으로 쓰러뜨린 적 / 은신 제압으로 쓰러뜨린 적 / 기타의 방법으로 쓰러뜨린 적

스크린샷의 치명적인 신체 피해로 제압한 적은 원본 주석에서 비살상 마지막 타격이며 죽이지 않은 적을 세는 항목이므로 비치명적 피해로 제압한 적으로 바로잡았습니다. 통계 자체의 의미나 집계는 바꾸지 않았습니다.

MO2 적용:
1. 모드 전체를 교체했던 기존 한글화 버전을 비활성화합니다.
2. 첨부한 1.18 원본 ZIP을 원본 모드로 설치/활성화합니다. 기존 한글화로 바뀐 원본 스크립트를 그대로 쓰지 마세요.
3. 이 ZIP을 별도 번역 모드로 설치하고 원본과 함께 활성화합니다. 관리 편의상 원본 아래에 둡니다.
4. 원본 r6/scripts/UltimateKillCounter.reds와 새 r6/scripts/UltimateKillCounterKR/UltimateKillCounter_Korean.reds가 모두 적용되는지 확인합니다. 원본 파일을 덮어쓰지 않으므로 MO2에서 파일 충돌 표시가 없는 것이 정상입니다.
5. 게임을 완전히 다시 실행하고 캐릭터 통계의 처치한 적 범주를 확인합니다.

수동 적용: 먼저 원본 1.18의 파일을 복구한 뒤 이 ZIP의 r6 폴더를 게임 폴더에 병합합니다.

원본 업데이트:
원본을 업데이트해도 번역 확장은 별도 모드로 남고 원본의 집계/저장 코드를 덮어쓰지 않습니다. 다만 LocalizeTag 함수의 이름/인자/기본 문구가 바뀌면 번역 확장도 재검증해야 합니다. 새 문구는 인식되지 않을 경우 원본으로 넘기며, 함수 자체가 없어지거나 시그니처가 바뀌면 컴파일 오류가 발생할 수 있으므로 무조건 미래 버전에 호환되는 것은 아닙니다.

검증: 원본의 12개 태그/기본 문구 쌍과 패치 매핑 일치, 공유 키 항목의 번역 구분, 미인식 호출의 원본 위임 경로, 집계/상태 변경 코드 없음, 원본 파일 교체 없음, ZIP CRC 통과. 실제 REDscript 컴파일/게임 실행은 아직 미검증입니다. 문제가 있으면 최신 redscript_rCURRENT.log를 첨부해주세요.

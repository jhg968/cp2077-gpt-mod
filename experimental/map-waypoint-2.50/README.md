# Map Waypoint Bug Fixes 1.1.0 — CP2077 2.50 실험용 패치

이 패치는 사용자가 제공한 DLL의 지원 게임 빌드 선언만 변경한 비공식 테스트용입니다.
게임 기능 호환성은 검증하지 않았으며 공식 업데이트를 대체하지 않습니다.

- 대상: Cyberpunk 2077 2.50 / 파일 빌드 3.0.88.46235 / RED4ext 1.31.0
- 원본: MapWaypointBugFixes.dll 1.1.0, 지원 빌드 3.0.80.51928
- 변경: Query의 빌드 선언을 3.0.88.46235로 변경. 파일 오프셋 0xDE84, 0xDE86, 0xDE87의 총 3바이트.
- 게임 함수 주소, 후킹, 데이터 구조 및 스크립트는 변경하지 않았습니다.
- 검증: 원본 해시 확인, Query x86-64 에뮬레이션, 다른 PluginInfo 값 동일 확인, ZIP 무결성 검사.
- 미검증: Windows DLL 로딩 및 실제 게임 기능.

## 적용 및 원복

1. 게임을 종료하고 원본 Map Waypoint Bug Fixes 모드는 유지합니다.
2. ZIP을 MO2의 별도 모드로 설치하고 원본 DLL보다 높은 파일 우선순위를 지정합니다.
3. RED4ext 로그에서 MapWaypointBugFixes의 `has been loaded`를 확인합니다.
4. 중요한 세이브를 덮어쓰지 말고 테스트용 세이브로 지도 웨이포인트 설정/변경/해제와 경로 표시를 확인합니다.
5. 충돌 또는 기능 이상이 발생하면 실험용 패치 모드를 비활성화하여 원복합니다.

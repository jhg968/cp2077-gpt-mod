# Tech Weapons Charge Timings 2.0.3 한국어 언어 팩 v1

## 설치

1. 첨부 원본 Tech Weapons Charge Timings 2.0.3을 설치하고 활성화합니다.
2. 이 ZIP을 MO2에서 별도 모드로 설치하고 원본과 함께 활성화합니다. 원본보다 아래에 배치하면 됩니다.
3. 게임을 실행하고 CET 오버레이를 연 뒤 Tech Weapons Charge Timings 창 상단의 Language에서 `한국어 (lang_ko)`를 선택합니다.
4. 선택은 원본 기능이 init.lua의 ChargeTimings.language 값에 저장합니다. 쓰기 실패 안내가 나온다면 원본이 안내하는 설정 파일에 대한 쓰기 권한을 확인하세요. 이 언어 팩은 init.lua나 개인 프로필을 포함하지 않습니다.
5. 한글이 네모로 보이면 CET 오버레이 설정에서 한글 글리프가 포함된 글꼴을 선택하세요.

## 변경 범위

공식 언어 파일 자동 탐색 기능을 사용해 `bin/x64/plugins/cyber_engine_tweaks/mods/Tech Weapons Charge Timings/lang/lang_ko.lua` 한 파일만 추가합니다. 설정 화면·도움말·프리셋 설명·상태 메시지·CET 콘솔 안내 등 영어 템플릿의 84개 항목을 번역했습니다.

충전 시간, 볼트 판정 구간, 프로필 적용 순서, 프리셋 수치, 원본 코드 및 개인 설정은 변경하지 않습니다. active 및 chargeTimeModifier 등 프로필용 내부 매개변수 이름은 원본 설계대로 영어로 유지됩니다. 무기 이름은 게임 언어를 따르며 로그 파일과 고정 영문 로고도 유지됩니다. Internal Clock 및 In Charge 특전은 원문 이름으로 표기합니다.

원본 2.0.3 변경 로그에 따르면 구형 1.1.0의 개별 변형 모드들은 먼저 비활성화해야 합니다. Very Fast, Max Charge Bolts 등의 기능은 새 버전 창의 프리셋으로 선택합니다. 이 언어 팩 자체는 기존 변형을 제거하거나 변경하지 않습니다.

## 검증

- 입력 ZIP 무결성 검사.
- LuaJIT에서 언어 파일 문법 및 테이블 로드.
- 영어 템플릿의 84개 키 전체 포함, 모든 {placeholder} 보존과 실제 치환 확인.
- 원본 init.lua의 번역 함수들로 언어 파일 탐색, 한국어 로드, 영어/한국어 전환 및 누락 키의 영어 대체 확인.
- 영어 로그 문구 유지 확인.
- 실제 게임 화면·CET 글꼴·언어 저장 지속성은 검증하지 못했습니다.

원본을 업데이트하면 언어 선택이 영어로 돌아갈 수 있으므로 다시 한국어를 선택하세요. 향후 lang_en.lua에 키가 추가되면 이 언어 팩도 비교·보완이 필요합니다.

# Inventory Adjustments Hub 1.5 한국어 패치 v1

## 설치

1. Inventory Adjustments Hub 1.5 원본을 설치하고 활성화합니다. 원본의 필수 모드도 설치되어 있어야 합니다.
2. 이 ZIP을 MO2에서 별도 모드로 설치하고 원본보다 아래에 배치합니다.
3. `r6/scripts/InventoryAdjustmentsHub/locales/kr-kr.reds`의 최종 제공 모드가 이 패치인지 확인합니다. 다른 IAHub 한글 패치가 있다면 비활성화하거나 이 패치가 우선하도록 설정합니다.
4. 게임을 한국어로 실행하고 설정의 모드 설정 메뉴에서 `Inventory Adjustments Hub`를 확인합니다. 별도 언어 선택은 필요하지 않습니다.

## 번역 범위

- 설정 분류, 옵션 이름·설명·선택값, 추가 무기 능력치, 의상 가격대·스타일·소속 태그 등 영어 템플릿의 209개 키를 제공.
- 원본 한국어 파일의 미번역 문구 및 Magazine/Hip Fire 등의 오역 수정.
- 한국어 파일에서 누락된 1.5 옵션(개조 부품 표시 열 수, 무기 제조사 로고) 4개 문구와 모드명 키 추가.
- 원본의 기존 Codeware 한국어 등록 구조 사용. 한국어 패키지 파일 하나만 교체.
- 모드명 `Inventory Adjustments Hub`, DPS, NCPD, 표시 방식 V1/V2 등의 식별용 표기는 유지.
- 원본 archive, config, 기능 스크립트, 능력치·정렬·표시 설정 기본값은 포함하거나 변경하지 않음.

## 검증과 한계

- 입력 ZIP 무결성 검사 통과.
- 영어 1.5 템플릿과 키 209개 및 순서 일치, 중복 키 없음.
- 설정 파일이 참조하는 번역 키 158개 모두 포함.
- 출력은 영어 템플릿에서 Korean 클래스명과 표시 문자열만 변경했는지 확인.
- 원본 한국어 제공자 등록과 UTF-8 문자열 이스케이프·서식 토큰 확인.
- 실제 redscript 컴파일과 게임 화면 검증은 수행하지 못함. 설치 후 `r6/logs/redscript_rCURRENT.log`와 모드 설정 화면으로 확인 가능.
- 이후 원본 업데이트에서는 locales/en-us.reds의 새 키와 구조 변경 여부를 비교해야 함.

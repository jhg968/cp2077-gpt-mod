# AutoGorilla v0.4.2 — 중복/늦은 가드 억제 시험판

## 이번 로그에서 확인한 점
측정 구간의 실제 피격13회는 모두 NPC 공격 상태 진입 후 0.160~0.176초에 도달했습니다.
동일한 관측 공격 상태에 반복 진입하거나, 상태가 시작된 지 0.5초 이상 지나 새로 가드를 여는 사례가 있었습니다.
가드를 연 준비 상태와 실제 타격이 발생한 다음 공격 상태가 다른 사례도 있었습니다.
이는 해당 대련 표본의 결과이며 모든 NPC 공격에 동일한 타이밍이 적용된다고 주장하지 않습니다.

## 변경
- NPC별 관측 공격 상태 주기당 자동 방어 시도를 한 번만 허용합니다.
- 시작 시점을 확인한 공격 상태의 최초0.12초 안에서만 새 자동 Deflect를 준비합니다.
- 시작을 중간에 관측해 시점을 모르는 공격 상태는 제외합니다.
- 실제 NPC 상태 변경 알림에서 정면3m 안 새 공격을 후보로 등록합니다. 조준점 기준 가장 가까운 한 명만 보던 누락을 줄이기 위한 것입니다.
- 패링 간격 쿨다운은 실패한 가드 시도마다 걸지 않고, 기본 패링 성공 뒤에만 적용합니다.
- NPC 상태 추적은 진단 로그가 꺼져도 동작합니다. 로그 스위치는 기록 여부만 바꿉니다.
- 기본 패링 시간창/공격 판정/성공 이벤트/반격 레코드/공격 생성은 유지합니다.

공격 상태 주기는 실제 고유 공격 한 번과 항상 같지는 않습니다. 한 상태에 여러 연속타가 포함되면 놓칠 수 있습니다.
0.12초 제한은 이번0.16~0.18초 피격 표본에서 늦은 진입을 피하기 위한 보수적 첫 값입니다.
서로 다른 느린 공격, 시작 상태 통지가 없는 공격, 다른 NPC/보스는 추가 검증이 필요합니다.
준비 동작 자체에 한 번 가드를 올리는 것은 여전히 있을 수 있습니다. 움찔거림 완전 제거/모든 공격 성공은 보장하지 않습니다.

## 설치와 테스트
1. 게임 종료 후 이전 AutoGorilla와 별도 NativeTrace를 모두 비활성화합니다.
2. AutoGorilla-v0.4.2-native-first.zip을 MO2에 설치하고 이 버전만 활성화합니다.
3. Native Settings UI/CET/redscript는 유지하고 MO2로 실행합니다.
4. Mods → AutoGorilla에서 자동 패링/자동 반격/진단 로그를 켭니다.
5. 추가비용0, 패링 성공 후 최소 간격0.3초, 피해 배율1.0으로 둡니다.
6. 같은 상대와 가까이 마주 보고 약20초 공격받습니다. 불필요한 가드가 줄었는지와 실제 반격/적 피해를 함께 확인합니다.
7. AutoGorilla.log를 보내주세요. 컴파일 오류라면 redscript_rCURRENT.log가 필요합니다.
테스트용 저장을 사용하고 필요하면 수동 방어로 전투를 끝내세요. 수동 입력이 섞여도 괜찮습니다.

## 설정과 범위
기본값은 추가비용10/최소 간격1.2초/피해 배율1입니다. 위 첫 테스트 값으로 변경하세요.
간격 항목은 이제 '패링 성공 후 최소 간격'이며, 실패한 시도에는 적용하지 않습니다.
추가비용0은 모드의 추가 비용만 없앱니다. 기본 반격 자체 비용은 남습니다.
설정은 즉시 적용하고 JSON에 저장합니다. 개인 settings.json은 ZIP에 포함하지 않습니다.
기존 모드 폴더/Overwrite 설정을 보존하거나 UI에서 다시 설정하세요.
고릴라 암 근접 대기 상태가 대상입니다. 공격/차지/회피 중 자동 발동은 확대하지 않았습니다.
보스/맥스택/적대 관계로 제외하지 않습니다. 기본 피격 판정은 게임에 맡깁니다.
카타나/다른 근접 무기/총알 반사는 아직 없습니다.
가짜 패링 플래그, 성공 이벤트 억제, 피격 이벤트 보류, 별도 가짜 피해를 사용하지 않습니다.
기본 근접 조준 보정은 유지됩니다.

## 로그
전용: bin/x64/plugins/cyber_engine_tweaks/mods/AutoGorilla/AutoGorilla.log
공통: bin/x64/plugins/cyber_engine_tweaks/scripting.log
컴파일: r6/logs/redscript_rCURRENT.log
MO2 Overwrite에도 있을 수 있습니다. 최신 v0.4.2 이후 기록을 확인하세요.
AUTO native Deflect entered / AUTO native parry confirmed / AUTO original counter entered로 단계별 결과를 봅니다.
SpawnAttackGameEffect started=1은 기본 공격 시작 성공, native damage event actualResourcesLost는 게임 피해 이벤트입니다.
sensor의 attack_state_too_old / same_state_already_attempted / attack_start_unknown은 자동 준비를 제외한 이유입니다.
TIMING phase/contact는 상대ID/관측 주기/공격 레코드/피격 시점을 연결합니다.
cycle은 고유 애니메이션 공격ID로 단정하지 않습니다.

## 검증
41개 wrapper 선언을 공개 게임2.5 소스와 대조했습니다.
설정/UI/JSON 저장/로드/로그 배출의 Lua 모의 테스트와 ZIP 내용/무결성 검사를 통과했습니다.
기존 기록의 가드17회 중7회가 새 신선도/중복 필터를 통과했습니다. 기록 재생 점검이며 새 버전 성공률 예측이 아닙니다.
후보 선택/상태 주기 소모/쿨다운 변경의 실제 게임 동작과 이번 게임용 컴파일은 아직 미검증입니다.
사용자 로그 원문/개인 경로/게임 및 기반 모드 파일은 공개 배포물에 포함하지 않았습니다.
